Focus

Built a full-stack productivity tracker for logging tasks, tracking focus, generating summaries, and searching past work.

Role

Designed the interface, built the React frontend, structured the API and database, and integrated AI-powered reporting features.

Tools

React, Vite, CSS Modules, Express, PostgreSQL, Claude API, ChromaDB, and Postico2.

Technical writeup

Decisions behind the productivity tracker.

Frontend

I used React because it fits the interactive parts of the app well and matched the framework I was most comfortable building in. Vite kept the setup lightweight with a fast dev server, which made local iteration quicker while working through the tracker flows.

Styling

I kept the styling in CSS Modules so each component could have scoped styles without adding a larger CSS framework. This kept the codebase easier to reason about and avoided class naming conflicts while still keeping the CSS organized in separate files.

Backend

The backend uses Express with PostgreSQL. Express was enough for a focused API server, and PostgreSQL was a good fit for reliable task storage, date and time fields, and structured data that could later support reporting and filtering.

Data model

I kept the database schema intentionally simple: an auto-incrementing task id, date, focus level, description, and time spent. These fields captured the core information needed to track work without making task entry feel too heavy.

AI features

I used the Claude API for daily reports, task statistics, and natural language summaries because it handled context well and was straightforward to integrate. I added ChromaDB for local semantic search so tasks could be found by meaning instead of only exact keywords.

Future work

Future improvements could include authentication, stronger data visualizations, import and export tools, and more responsive mobile polish. For this version, the focus was a local app that tracks tasks, generates insights, and helps make productivity patterns more visible.
