Case study

From redesign to production release.

Challenge

The site needed to feel more credible to technical, government, and business audiences while becoming easier to update and release.

Design

Reorganized content and created high-fidelity Figma layouts for the major pages, with clearer hierarchy, navigation, and page patterns.

Build

Translated the approved designs into responsive HTML and CSS, preserving the visual system across desktop, tablet, and mobile.

Release

Built a GitLab CI/CD workflow with GitLab runners to deploy across three AWS EC2 instances, reducing releases from about 30 minutes to under two.

Validation

Used Chrome DevTools and Microsoft Clarity to debug frontend issues, identify friction points, and refine the site with stakeholder feedback.

Result

  • Production-ready redesign with responsive layouts.
  • More consistent release process across infrastructure.
  • Clearer maintenance path for future updates.
