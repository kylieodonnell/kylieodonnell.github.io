# Kylie O'Donnell Portfolio - GitHub Pages Version

This folder is a static version of the portfolio. It does not require Next.js,
React, npm, or a build step.

## Files

- `index.html` - the portfolio page
- `styles.css` - the site styling
- `assets/` - portfolio images, favicon, and social preview image

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload everything inside this folder to the repository root.
3. In GitHub, open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root`, then save.

GitHub will publish the site at:

`https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`

If you use a custom domain later, update the Open Graph image URLs in
`index.html` to use the full custom-domain URL.
