Mobile UI

Crib

Crib is a mobile app designed to help housemates manage shared responsibilities and communicate more clearly. It gives roommates a simple way to assign household tasks, track who is responsible for what, and make group decisions without relying on scattered messages or awkward conversations.

A core feature is anonymous polling, which allows housemates to vote on shared decisions and resolve disagreements more calmly and fairly.

View full Figma file GitHub repo

Project details

Mobile-first household coordination.

Focus

Designed a mobile-first experience for task delegation, household coordination, and anonymous group voting.

Role

Led the Figma design for the project as the primary designer, mapping the onboarding and core user flows, organizing task-assignment interactions, and refining the visual hierarchy. Also used CSS to help implement the Figma design into a clickable mid-fidelity prototype.

Key features

Task assignment, shared household responsibilities, anonymous polls, account creation, household setup, and first-time onboarding.

Tools

Figma, mobile UI design, user flows, information architecture, and mid-fidelity prototyping.
